# bioinf | Learning Bioinformatics Through Code

**From Biomedicine to computational biology, one project at a time.**

Welcome! I'm a Biomedicine graduate currently pursuing a Master's in Bioinformatics. My background in experimental and translational research sparked my interest in how programming and data analysis can help us explore complex biological questions.

This repository is a record of that transition: a growing collection of programming exercises, study notes and academic work in Python, R and biomedical data analysis.

## What I'm learning

- **Python:** programming fundamentals, problem-solving and data manipulation.
- **R:** statistical programming, exploratory analysis and data visualisation.
- **Biomedical data analysis:** cleaning, exploring and interpreting biological and health-related datasets.
- **Bioinformatics:** connecting biological knowledge with reproducible computational methods.

My wider Master's coursework also covers SQL, Linux and biological sequence analysis. I'll add new material here as I develop and document those skills.

## Where I want to go

I'm especially interested in the intersection of **computational biology, data science and AI for life sciences**. My goal is to build the technical foundations needed to contribute to meaningful scientific research.

This is a **learning portfolio**, not a collection of finished software products. I update it as I practise, improve and take on more complete projects.
